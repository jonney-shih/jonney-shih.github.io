# personal-website

Minimal bilingual (中文 / EN) static personal site. No build step.

- `index.html` — content (edit the text and links)
- `style.css` — styling (auto light/dark)
- `script.js` — language toggle

Preview: open `index.html`, or run `python -m http.server 8000` in this folder.
Deploy: push to GitHub and enable Pages (or any static host).
